# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, criticise designs and results, not
people. Cryptanalysis of this hash, however damaging, is welcome.

Report unacceptable behaviour to the maintainer, Jyrki Alakuijala, through
the contact details on his GitHub profile.
